Judges & Architecture Note:
In Chrome Manifest V3, Web Speech API recognition on external websites executes under the origin of each visited webpage (e.g., https://wikipedia.org). When Sleepwalker is clicked on a new website, Chrome displays the standard permission prompt once for that site. Chrome caches the permission permanently for that origin. Additionally, Sleepwalker provides a 100% functional typed input companion on the floating pill so low-speech or microphone-restricted users are never locked out.
